Place Temp.docx here so the app can auto-load it during development.

Steps:
1. Copy your `Temp.docx` into this `public/` folder.
2. Run the dev server:

```bash
npm run dev
```

3. Open the app; it will attempt to fetch `/Temp.docx` and set it as the default template.

If you prefer the file served from another location, update `src/App.tsx` accordingly.
